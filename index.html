How do I get a free API key?
  1. Open api.esv.org in your browser.
  2. Create a new account, or simply log in at https://api.esv.org/login/
  3. On your https://api.esv.org/account/ page, click on Create an API Application.
  4. Enter an application name (e.g. “SJT Readings”), select “Personal Study” as the intended use, and answer any other questions. Now click the Create Application button.
  5. When viewing your new application, copy your API Key (the long string of numbers next to “Authorization: Token ” underneath the “Application Keys” section).
  6. Come back here, paste it into the box below, and tap Save.

The key is free and for your own personal use. Please don’t share it. The wording and links on esv.org might be different or could change over time.
